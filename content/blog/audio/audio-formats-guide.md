# The Ultimate Guide to Audio Formats

Audio formats can be broadly categorized into three types: Uncompressed, Lossless compressed, and Lossy compressed.

## Uncompressed (WAV, AIFF)
These files represent the exact audio as it was recorded. They are huge in size but perfect for editing.

## Lossless (FLAC, ALAC)
These compress the audio without losing any data. Think of it like a ZIP file for audio.

## Lossy (MP3, AAC, OGG)
These formats discard data that the human ear can barely hear to drastically reduce file sizes.
